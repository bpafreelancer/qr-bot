# QR-бот для Telegram на Vercel

Минималистичный Telegram-бот: принимает текстовое сообщение — отвечает PNG-картинкой с QR-кодом.
Отвечает **только одному** Telegram-ID (`TG_ID`). Всем остальным — полная тишина.

Работает как Vercel Serverless Function через webhook. Без polling, без долгих процессов.

---

## Возможности

- 📥 Принимает **только текст** (фото/стикеры/файлы игнорируются)
- 🔒 Реагирует **только** на сообщения от `TG_ID`, чужим не отвечает вообще
- 🖼 Генерирует PNG 512×512 (уровень коррекции `M`, поля 2 модуля)
- ↩️ Отправляет QR как **ответ на исходное сообщение**
- ⚠️ Если текст длиннее 2000 символов — отвечает предупреждением (только тебе)
- ⚡ Работает на Vercel Hobby (лимит функции — 10 секунд)
